AttendanceChimp

The application tracks class attendance using QR codes, stores data in a relational database, and exposes its functionality through a web interface and API endpoints.

AttendanceChimp is a web application for college instructors:

  1. The instructor logs in and generates a unique QR code for a class session.
  2. The QR code is projected on a classroom screen.
  3. Students photograph the QR code with their phones and upload the image to the application.
  4. The application decodes the QR code, matches it to the lecture, and records the student's attendance.
